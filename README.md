# 하나 프로젝트 AX (HANA Project AX)

전기·통신공사 문의부터 견적, 현장, 준공, 수금까지 한 번에 —
충남 보령의 전기·통신공사업체 **하나정보통신**과 프로젝트 기획·운영관리 파트너
**하나컨설팅**이 함께 쓰는 운영 SaaS 데모입니다.

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:3000)
npm run build    # 프로덕션 빌드
npm run start    # 프로덕션 서버
```

로그인·백엔드 없이 로컬 샘플 데이터로 바로 실행됩니다. (데모 기준일: 2026년 7월)

## 주요 화면

| 메뉴 | 내용 |
| --- | --- |
| 오늘 | KPI, AI 브리핑, 오늘 확인할 일, 진행 중 프로젝트 |
| 문의·견적 | 영업 파이프라인, 재접촉 알림, 다음 달 매출 예측 |
| 고객·재수주 | 고객 이력과 재수주 추천 |
| 프로젝트 | 목록·필터, 상세 8개 탭(공정, 원가·수익, 현장일보, 추가공사, 준공·정산, 문서, 하나컨설팅) |
| 현장일보 | 일보 작성 + AI 현장보고서 생성 |
| 추가공사 | 구두 요청 경고, 단계별 상태 관리 |
| 원가·수익 | 공정률 대비 원가 투입률 위험 탐지, 이익 비교 차트 |
| 준공·수금 | 준공 체크리스트, 수금 현황, 미수금 알림 |
| 하나컨설팅 | 프로젝트별 정산, 업무량 기반 관리용역비 계산기 |
| 문서함 | 분류·통합 검색, 프로젝트별 문서 현황 |
| 대표 승인함 | 견적·추가공사·자재·용역비·잔금 승인/반려 |

이외에 헤더의 사업자 전환(전체/하나정보통신/하나컨설팅), 전화메모 AI 정리
기능을 제공합니다.

## 기술 스택

Next.js (App Router) · TypeScript · Tailwind CSS 4 · Recharts · Lucide React

## 역할 구분

- **하나정보통신** — 발주처 계약, 시공, 자재, 인력, 안전관리, 준공 책임, 대금 청구
- **하나컨설팅** — 사전검토, 공정계획 지원, 자료관리, 원가분석 등 프로젝트 기획·운영관리
