판정
- **A1~A14와 필수 항목 A16·A17 · A18·A19·A20·A22(0.6.1 추가)가 모두 통과하면** 시험 B·C·D를 시작한다. (A15 안전점검은 시험 C 전에 다시 본다)
- A16·A17은 0.3.1 로컬 화면시험에서 **간헐적으로 실패했던 두 화면**이다(사후 입력 '작업 종료 기록됨' 30초 초과 · 일정 취소 뒤 '이동 기준 재확인 필요' 요약 확인 실패). 다시 돌리면 통과했고, **원인은 확정하지 못했다** (`docs/FIELD_SYSTEM_OPERATIONS_READINESS.md` ③-2). 실기기에서 같은 동작을 **3번씩** 하고, 안내나 요약이 늦게 보이거나 사라지면 시각·기기·화면 사진과 함께 **오류**로 남긴다.
- 하나라도 실패하면 성과 측정 화면에 **오류**로 남긴다. 기기·시각·화면 사진을 함께 적는다. 고친 뒤 같은 항목을 다시 시험하고 **개선 반영**으로 연결한다.
- 시험 A의 결과 문서는 '실제 기기 연동 확인'이다. 현장 효과의 근거가 아니다.

| 5 | 현장기사 → 관리자 | 해결 보고 → 해결 확인 (또는 미해결 유지) | 발생→해결 |
| 6 | 관리자 | 그날 사건 증빙 PDF · JSON 보관 | 사건번호 `HX-…` |

- 전화로만 들은 내용은 관리자가 **대리 입력**한다 (자료 출처 '전화' · 사후 입력 · 시각 근거). 수행자 구분은 '진행자 입력'이 된다.

### 2-3. 시험 B-2 — 실제 과거 현장정보 재현 (원자료가 있을 때만)

| 단계 | 할 일 |
|---|---|
| 1 | 지난 사례의 **원자료**를 모은다 (업무일지 · 통화기록 · 메신저 · 일정표). 원본은 회사가 보관하고, 프로그램에는 원자료 이름만 적는다 (예: "2026-10-02 업무일지 · A현장 통화기록") |
| 2 | 관리자가 **검증 시나리오** 날짜에 그날 일정을 원자료대로 다시 등록한다 |
| 3 | 보고 화면 자료 구분: **실제 과거 현장정보 재현 (원자료 있음)** → 원자료 이름 입력 |
| 4 | 사후 입력으로 보고·조치를 넣고, 시각마다 근거를 고른다: 원자료 기록 / 현장 직원 진술 / 기억에 의한 추정 / 모름 |
| 5 | 진술·추정은 그렇게 표시된다. '기억에 의한 추정'은 통계에서 빠진다 |

원자료가 없는 사례는 재현으로 만들지 않는다. 시험이 필요하면 **가상 시나리오**로 만들고 그렇게 표시한다.

### 2-4. 시험 C — 안전점검 (실제 업무 권장)

| 단계 | 누가 | 할 일 | 확인 |
|---|---|---|---|
| 1 | 현장기사 | 작업 전 '시작 전 점검': 필수 3항목(안전모 · 안전화 · 작업구역) + 착용 사진 | 사진 없이 제출 불가 · 필수 항목 '해당 없음' 불가 |
| 2 | 현장기사 | 미흡이 있으면 **작업을 멈추고 본사에 전화** (화면 안내) | 안내 문구 · 상태 '확인 대기' |
| 3 | 관리자 | 사진을 직접 보고 적합(육안 확인) 또는 보완 요청 | 미흡이 있으면 적합 불가 |
| 4 | 현장기사 | 보완 사진 제출 → 관리자 조치 완료 확인 | 이력은 추가만 |
| 5 | 현장기사 | 진행 중 · 마친 뒤 점검 | 단계별 기록 |

점검 항목 8개(필수 3)는 **초안**이다. 시험 C 전에 회사 안전기준으로 확정한다.

### 2-5. 시험 D — 수기 방식 vs AX 방식 (측정 7)

| 항목 | 방법 |
|---|---|
| 시나리오 | 진행자(참가자 아님)가 인터뷰 사실 ①②③⑤를 바탕으로 만든다. 실제 과거 사례면 원자료와 함께 '실제 과거 현장정보 재현', 만든 상황이면 '가상 시나리오' |
| 정답표 | 시험 전에 진행자가 위험한 연결과 영향받는 현장을 적어 둔다 (참가자에게 보여 주지 않음) |
| 짝 | 같은 시나리오의 수기·AX 측정에 같은 '대응 묶음' 이름을 붙인다 |
| 학습 효과 줄이기 | 참가자마다 순서를 바꾼다 (1번 참가자: 수기 → AX, 2번 참가자: AX → 수기). 같은 참가자에게는 **난이도가 대응되는 다른 시나리오**를 쓴다 (현장 수 · 지연 분 · 연결 수를 맞춤) |
| 수기 방식 | 종이 일정표 · 전화 메모로 위험을 찾는다. 진행자가 앱 측정기로 시작 → 위험 파악 끝을 잰다 |
| AX 방식 | 같은 참가자가 시스템 화면으로 찾는다. 같은 측정기를 쓴다 |
| 채점 | 정확히 찾은 위험 / 정답 위험 수 · 놓친 위험 · 잘못 판단한 위험 |
| 값의 근거 | 시험 실측 / 과거 기록 / 기억 추정 (기억 추정은 비교에서 빠짐) |
| 수행자 | 구본석 이사가 직접 화면을 누르면 본인 계정으로 입력하고, 컨설턴트가 진행하며 입력하면 진행자 계정이 된다. 시험 일지에 '직접 수행 / 진행자 진행'을 적는다 |
| 결과 표시 | 같은 자료 구분 안에서 수기·AX가 모두 있을 때만 '이번 측정값 (n, 중앙값 차이) · 통계적 유의성 검정 아님' |
