# 기술검증영상 바로가기 PDF (A4 한 장)

이전에 제출용으로 만든 바로가기 PDF와 같은 모양으로 다시 만들었다.
- 페이지 아무 곳이나 누르면 구글 드라이브의 영상이 열린다. 링크 영역은 0,0,595,842pt로 페이지 전체이다.
- **링크** (2026-11-26 사용자 제공): https://drive.google.com/file/d/1IYKjgLSN0VwXutS2YbAkdVhaK05q-R9Z/view?usp=sharing
  - 연결된 파일: "(주)하나정보통신 복수현장업무위험관리AX 소개영상_261120.mp4"
  - 122,232,757바이트로 5판 원본과 같다.
  - 공개 범위: 링크가 있는 사람 보기
- **썸네일**: 5판 영상과 같은 디자인이다.
  - 남색 + 금색 + 흐름선 배경
  - 실제 PC · 휴대폰 화면에 금색 번호 표시
  - 오른쪽 아래에 '영상 보기' 단추

## 다시 만들기
1. `thumb.py`, `shot.mjs`: 썸네일 HTML과 PNG(1920×1080)를 만든다. 영상 도구 `v3/`(lib3 · assets3)를 쓴다.
2. `page.html`: A4 배치이다. 렌더 전에 `%FONT%`는 Pretendard 경로로, `%URL%`은 영상 링크로 바꾼다.
3. `node pdf.mjs out.pdf`: Chromium으로 PDF를 만든다.
