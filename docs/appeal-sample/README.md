# 이의신청 보완자료 샘플 (2026-11-22 · 간결판 9쪽 / 상세판 14쪽)

> **2026-11-23 — 최종 보완 패키지는 [`docs/appeal-package/`](../appeal-package/README.md) (13종 82쪽).** 이 폴더의 간결판 · 상세판은 그 바탕이 된 샘플이다.

세 가지 현장 문제(초급 기술자 보고 지연 · 안전확인 지연 · 다음 현장 지연 전파)를 **실제 프로그램 화면**으로 절차대로 보여 주는 A4 자료의 샘플이다.
디자인은 회사가 만든 참고 PDF(「이의신청 보완자료 구성 예시」 12쪽)를 따랐고, '처음 보는 사람이 바로 이해하는 것'을 기준으로 다시 짰다.

## 두 가지 판
| 판 | 파일 | 쓰임 |
|---|---|---|
| **간결판 (9쪽)** | `appeal-sample-simple.pdf` · `simple.html` · `img-simple/` | 처음 보는 심사위원용 — 한 쪽 한 메시지, 핵심 문장 · 키워드와 화면만 |
| 상세판 (14쪽) | `appeal-sample.pdf` · `appeal.html` · `img/` | 단계별 설명 · 측정 기록 · 용어 풀이까지 — 질문이 오면 근거로 |

간결판 구성: 표지 → 한 장 그림 → 문제 1 → 문제 2 → 문제 3(계산) → 문제 3(조치 후 다시 계산) → 근거 → 심사 질문 한 줄 답 → 다음 단계.
두 판 모두 같은 촬영(11:00 정각)의 같은 화면을 쓴다.

| 부록 A · B | 사건 증빙 화면 · 쉬운 용어 풀이 |

## 화면 표시 방식
- 화면마다 핵심 부분만 잘라 크게 보이고, 볼 곳에 빨간 테두리와 ①②③을 겹친다. 아래 설명 번호가 같다.
- 표시 위치는 촬영할 때 프로그램 화면의 실제 요소 위치를 재서 저장한다(손으로 그리지 않음).

## 화면은 어떻게 찍었나
- `tests-pilot/e2e/appeal-shots.mjs` — 로컬 서버 · 로컬 DB에서 실제 프로그램을 자동으로 조작하며 찍는다. 예정 시작을 정각(`APPEAL_P=11:00`)으로 주면 11:00 시작 → 11:30 중간 확인 → 13:00 예상 종료처럼 읽기 쉬운 시각이 된다. '중간 확인'은 실제로 30분이 지나야 뜬다(약 45분).
- 자료 구분은 '검증 시나리오(가상)', 인물 · 현장 · 사진('시험용 이미지')은 시험용이다. 관리자 PC와 기사 휴대폰은 같은 컴퓨터의 별도 브라우저 세션이다(실제 휴대폰 아님).
- 일정 간격 · 이동시간이 핵심 사례(`docs/VENTURE_CORE_CASE.md`)와 같아 계산 결과(50분 · 45분 부족 → 조치 후 0)도 같다.

## 쓰지 않은 것
- 측정하지 않은 개선 수치(참고 PDF 7쪽의 '70분 → 15분' 등)는 넣지 않았다. 대신 실제 현장에서 같은 정의로 잴 지표를 적었다.
- 실제 현장 실증 결과는 0건이다. 문서에도 그렇게 적었다.

## 회사가 채울 것

## 다시 만들기
```bash
# 1) 화면 촬영 (로컬 Supabase · next start -p 3197 실행 중) — 정각 10분 전쯤 시작
APPEAL_P=11:00 APPEAL_OUT=/tmp/appeal node tests-pilot/e2e/appeal-shots.mjs
# 2) 시험 기록(로컬 DB)에서 사건번호 · 발견/보고 · 조치 시각
python3 docs/appeal-sample/facts.py /tmp/appeal/facts.json
# 3) 문서 · PDF
python3 docs/appeal-sample/make.py /tmp/appeal docs/appeal-sample/photos
node docs/appeal-sample/render.mjs docs/appeal-sample/appeal-sample.pdf
# 간결판
python3 docs/appeal-sample/make_simple.py /tmp/appeal docs/appeal-sample/photos
APPEAL_HTML=simple.html node docs/appeal-sample/render.mjs docs/appeal-sample/appeal-sample-simple.pdf
```
